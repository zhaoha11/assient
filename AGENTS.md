# Project Handoff Rules

Before analyzing or changing this project, read `context/README.md` and
`context/WORKLOG.md`.

After every implemented feature, fix, protocol change, build result, or local
Git commit, update `context/WORKLOG.md` in the same change. Record the goal,
affected files, behavior change, verification result, commit ID, and any
remaining limitation. Keep `context/CONTEXT.md` limited to domain terminology.
