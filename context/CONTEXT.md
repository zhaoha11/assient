# ECloudAssistant 信令控制

本上下文定义远程控制信令中的设备身份与控制会话术语，避免将设备识别码与一次控制连接混为同一概念。

## Language

**设备连接**：
以数据库 `USER_CODE` 注册到信令服务器、可作为远程目标被查询的在线客户端连接。
_Avoid_: 房间、临时控制连接

**控制会话**：
控制端为一次远程连接创建并注册到信令服务器的临时身份；其生命周期与该控制连接一致。
_Avoid_: 设备码、被控端 code

**目标设备码**：
控制端发起远程请求时指定的设备连接 `USER_CODE`。
_Avoid_: 控制会话码、控制端身份

**控制权**：
设备连接在同一时刻只授予一个控制会话的输入转发权限；后续控制请求必须被拒绝。
_Avoid_: 多人协作控制、共享控制
